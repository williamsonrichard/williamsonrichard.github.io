Gjentakelse — Oracle bones

Can judge

inscribed oracle bones to be records, and the pits in which they were arranged to be archives. This is well-established in Chinese-language archival scholarship.

There can be considerable intellectual 'distance' between a Record or Record Set and an Instantiation of it, bridged by description.

Heidegger (§76 of Sein und Zeit)

intellectual engagement ('Wiederholung' — 'taking up again', building upon Kierkegaard) is necessary to pass from a 'mere' Instantiation (that is only 'vorhanden' — 'present-to-hand') to an authentic/real ('eigentlich' — in a deep, existential sense) Record.

Quite far

from the 'Dutch manual' (the Instantiation of a Record Set as primary, description a mere inventory). Akin instead to the 'post-custodial mindset' of Terry Cook.
